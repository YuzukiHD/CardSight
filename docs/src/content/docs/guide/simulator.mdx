The simulator on this page is the real UI compiled to WebAssembly: the same LVGL version, the same
five pages, the same widgets, fonts and glass material as `software/apps/cardsight/ui/`. It is not
a separate web mock-up. It opens on **Direct**; the tab bar at the bottom switches pages.

<Simulator />

## What it runs

- The firmware UI sources, compiled with Emscripten by `software/tests/wasm/`.
- A fixed card model: SK32G, 32 GB, three 10 GB partitions formatted as FAT32, exFAT and a
  read-only ext4.
- A request emulator that answers the worker messages the pages send: scanning, listing,
  starting and stopping USB, formatting and layout changes.
- A memory framebuffer, pointer input and a small scripted-scene layer for states that normally
  need a card insertion or a hardware fault.

## Using the simulator

The screen takes the same gestures as the panel: tap the tab bar to switch pages, drag a list to
scroll, and tap a partition, row or button to act on it. The shortcuts beside the screen cover the
actions that are awkward inside a small browser canvas:

- **Screen page** switches the five tabs without aiming at the tab bar.
- **Card and USB** inserts or ejects the card and starts or stops the USB link.
- **Demo states** jumps to the identifying overlay, the read-error sheet, the format dialog, the
  whole-card layout editor, a root file listing, or the initial demo state.

A short tour of the five pages, with what to try:

| Page | What to try |
| --- | --- |
| Direct | Watch the link state, then press **Connect USB** on the screen. |
| Proxy | Select partitions with the dots on the rows, then start the proxy. |
| Disk | Open a partition to format it; the last row opens the layout editor. |
| Files | Open the exFAT partition and browse directories; **Back** goes up one level. |
| Info | Scroll the card, bus and partition facts. |

The [on-screen UI](ui.md) page describes each page in full, including the states and error sheet.

## Limits

The simulator cannot:

- access a real card or a USB host;
- reproduce MMC timing, tuning, DMA or throughput;
- measure performance or match the panel's RGB666 data path exactly (the browser framebuffer is
  RGB565);
- persist changes between reloads.

The UI behaviour, layout, labels and state transitions are the real ones. Use the
[on-screen UI](ui.md) page for a description of each page, and
[Build](../development/build.md) for the simulator build steps.
