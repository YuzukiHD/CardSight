	<h2>Storage cards on a small screen</h2>
	<p>CardSight is a TF card proxy system for the Yuzuki CardSight board. It reads the TF card's partition table, formats partitions as FAT32, exFAT or ext4, browses directories, and combines selected partitions into one exFAT volume for the host over USB. The UI runs on a 240×284 ST7789 panel and is operated by touch.</p>

## What it does

- Identifies a TF card and negotiates SDR104 at 200 MHz, four-bit; parses MBR/GPT and lists each partition's filesystem, capacity and read-only state.
- Formats a single partition as FAT32, exFAT or ext4, and rebuilds a whole-card layout (MBR or GPT) before creating filesystems of the chosen type.
- Exports the card to a host as a USB mass-storage device. Direct mode exports the whole disk; proxy mode presents several partitions as one readable/writable exFAT view.
- Provides five touch pages: Direct, Proxy, Disk, Files and Info. Card removal, reinsertion, identification, and read/write failures each have a visible state.
- Keeps a serial shell for block devices, VFS, MMC, USB, the proxy and UI diagnostics, so the board can be debugged without a display or used in production testing.

## Verified on the board

| Item | Result |
| --- | --- |
| Boot | Three-stage RAM/FEL chain; FreeRTOS V11.3.3 kernel; image about 770 KiB |
| SD | SK32G 32 GB, SDR104 200 MHz four-bit, CMD19 tuning; 62 MiB/s measured into on-chip SRAM |
| Filesystems | FatFs (FAT/exFAT), lwext4 (ext4), VFS mount and format |
| Display/touch | ST7789 240×284, LVGL 9.6, CST816D touch; `cardsight ui-test` PASS |
| USB | MUSB + CherryUSB MSC; Windows mounts the exFAT volume; the same file read across three enumerations has the same SHA256 |
| Hot-plug | Real eject/reinsert during a USB export stops USB and the proxy safely, then identifies the card again |

The limitations and their causes are in [Hardware](/CardSight/hardware/): SMHC module-clock mux 2 is unusable, PSRAM writes run at about 10 MB/s, and data not yet flushed is lost when the card is removed. Those are not UI problems; the UI reports `flush failed` when it happens.
