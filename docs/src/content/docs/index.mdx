## 能做什么

- 识别 SD 卡并协商到 SDR104 200 MHz 四位；解析 MBR/GPT，列出每个分区的文件系统、容量和只读状态。
- 在 FAT32、exFAT、ext4 之间格式化单个分区；整盘重建分区表（MBR 或 GPT），再按选择的文件系统创建分区。
- 把卡作为 USB 大容量设备交给主机。直连模式导出整盘，代理模式把多个分区拼成一个只读/可写的 exFAT 视图。
- 触摸界面上有直连、代理、磁盘、文件、信息五个页面；拔卡、插回、识别中、读写失败都有对应状态。
- 串口命令行保留块设备、VFS、MMC、USB、代理和界面的诊断入口，方便无屏调试和产测。

## 已经在这块板子上跑通的

| 项目 | 结果 |
| --- | --- |
| 启动 | RAM/FEL 三步链，内核 FreeRTOS V11.3.3，镜像约 770 KiB |
| SD | SK32G 32 GB，SDR104 200 MHz 四位，CMD19 调谐；读入片上 SRAM 实测 62 MiB/s |
| 文件系统 | FatFs（FAT/exFAT）、lwext4（ext4）、VFS 挂载与格式化 |
| 显示/触摸 | ST7789 240×284，LVGL 9.6，CST816D 触摸；`cardsight ui-test` PASS |
| USB | MUSB + CherryUSB MSC；Windows 挂载 exFAT 卷，同一文件三次枚举的 SHA256 一致 |
| 热插拔 | USB 导出过程中真拔卡/插回，USB 与代理安全停止并重新识别 |

限制和原因写在[硬件说明](/CardSight/hardware/)里：SMHC 模块时钟 mux 2 不可用、PSRAM 写入约
10 MB/s、拔卡时未刷写的数据无法写回。这些不是界面问题，界面会把 `flush failed` 报出来。
