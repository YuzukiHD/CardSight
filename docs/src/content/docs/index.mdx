	<h2>A TF card proxy system on a small screen</h2>
	<p>CardSight reads a TF card, manages its partitions and filesystems, and exports the card or a synthesized exFAT view over USB. The five-page touch UI runs on a 240×284 ST7789 panel, and a serial shell covers diagnostics and recovery.</p>

## Try it

<Simulator />

The demo is the real LVGL UI compiled to WebAssembly, running a fixed 32 GB card model with three
10 GB partitions formatted as FAT32, exFAT and a read-only ext4. It cannot access a real card or USB
host, measure throughput, or keep changes after a reload.

## What it does

- Reads MBR and GPT partition tables and identifies FAT32, exFAT and ext4 volumes.
- Formats a partition as FAT32, exFAT or ext4, and rebuilds a whole-card layout.
- Browses directories on FAT, exFAT and ext4 through one VFS.
- Exports the whole card over USB, or a selected set of partitions as one synthesized exFAT view.
- Provides a five-page touch UI and a serial shell for diagnostics.

## Supported hardware

| Item | Detail |
| --- | --- |
| Board | Yuzuki CardSight, Allwinner V861/V881 (`sun252iw1`) |
| CPU | XuanTie C907 (RV32); E907 boot core |
| Memory | 128 KiB on-chip SRAM, 8 MiB PSRAM |
| Display | ST7789 240×284 on SPI1; CST816D touch on I2C0 |
| Card | SMHC0, TF card, SDR104/SDR50/SDR25, 1.8 V switching |
| USB | MUSB device controller, CherryUSB MSC |
| Console | UART0, PH13/PH14, 115200 8N1 |

More detail is in [Hardware](reference/hardware.md). Schematics, PCB and BOM are not published in
this repository yet.

## Project status

The source is an early public snapshot; only `master` is maintained. No prebuilt images are
published, so build from source. See the [changelog](https://github.com/YuzukiHD/CardSight/blob/master/CHANGELOG.md)
for the current snapshot and known limitations.
