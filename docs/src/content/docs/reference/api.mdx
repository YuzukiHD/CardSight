The C API reference is generated by Doxygen from the documented public headers. It covers the
platform interface, the VFS, the display port, USB mass storage, the storage proxy and the public
application and UI headers.

<LinkButton href="../../api/">Open the C API reference</LinkButton>

## Scope

Included:

- `software/include/` (`vfs.h`, `shell.h`, `hal/*`, `usb/mass_storage.h`, `gui/lvgl_port.h`,
  `drm/sunxi_display.h`);
- `software/apps/cardsight/storage/storage_proxy.h`;
- `software/apps/cardsight/storage/proxy_lazy.h`;
- `software/apps/cardsight/ui/ui.h`;
- `software/apps/cardsight/app/app.h`.

Private headers (`*_private.h`, `lazy_types.h`, `proxy_types.h`) and the third-party submodules are
excluded. The shell commands are documented in [Shell commands](cli.md); build and board settings
are in [Configuration](configuration.md) and [Hardware](hardware.md).

## Regenerate

From `docs/`:

```sh
sudo apt install doxygen
npm run api
```

The `api` script reads `docs/Doxyfile` and writes `docs/public/api/`, which is not tracked by git.
The normal `npm run build` runs it automatically. To skip it while working on Markdown, keep an
existing build and set `CARDSIGHT_SKIP_API=1`.

Doxygen uses `EXTRACT_ALL=NO`: a public symbol appears only when it has a documentation comment.
The generated HTML is linked from this page through `/api/`; the documentation site itself does not
parse or restyle it.
