# Support

## Read first

- Documentation: <https://yuzukihd.github.io/CardSight/>
- FAQ and troubleshooting: <https://yuzukihd.github.io/CardSight/project/faq/>
- Shell command reference: <https://yuzukihd.github.io/CardSight/reference/cli/>

## Asking for help

Use GitHub Issues for reproducible bugs and feature requests:

<https://github.com/YuzukiHD/CardSight/issues>

Include:

- the board revision and SoC variant;
- the CardSight commit or release;
- the build preset and toolchain version;
- the card model, capacity and filesystem;
- the exact commands and the serial log;
- what you expected and what happened.

Remove credentials, card contents and other private data from logs before posting.

## Security

Report vulnerabilities through [SECURITY.md](SECURITY.md). Do not open a public issue for a
security problem.

## Scope

Support is best effort. The maintainers do not provide a service-level agreement, hardware repair,
or support for modified boards. Questions about the XuanTie toolchain, SyterKit or an upstream
component belong in that project's tracker.

Hardware design files (schematics, PCB, BOM) are not published in this repository yet.
